## 预留建议（下次新模块）

从 **`1300000000560`** 起按模块预留整十/整二十号段（页 + 按钮 + 隐藏子路由），并同步改本表。（0550~0559 已占用）

## 脚本必须遵守

1. 新 Id：**先查登记表 → 再查库**  
   `SELECT Id, Name, Title FROM SysMenu WHERE Id BETWEEN @from AND @to`
2. `IF EXISTS UPDATE` **仅允许**更新「确认属于本模块」的行（如 `AND Name='hrXxx'`），禁止裸 Id UPDATE。
3. 推荐：`IF NOT EXISTS INSERT`；已存在且 Name/Permission 不符 → **报错退出**，不要覆盖。
4. 修冲突后把结论补进本表与当日 `doc/sql/{yyyy-MM-dd}/`。
