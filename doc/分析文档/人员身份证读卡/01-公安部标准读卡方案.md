# 人员资料 · 二代证读卡（公安部标准接口）

## 已拍板

- 路径：本机二代证读卡器 + **公安部标准 sdtapi**（不绑死单一品牌）
- 成功后一并覆盖：证号、姓名、性别、民族、出生、住址、照片、籍贯省市码等（布局无字段则跳过）
- 国籍空/`CN` 才读卡；非中国跳过

## 组成

| 组件 | 路径 |
|------|------|
| 本机 Agent | `Admin.NET/tools/IdCardReaderAgent` |
| 前端调用 | `Web/src/views/hrms/composables/hrIdCardReader.ts` |
| 按钮 | 人员编辑弹窗「读取身份证」→ `editEmp.vue` |
| 回填 | `empDynamicForm.applyDeviceCardResult` + `ParseIdCard` |

## 流程

1. 探活 `GET http://127.0.0.1:19196/health`
2. `POST /idcard/read` → sdtapi：`InitComm` → `Authenticate` → `ReadBaseInfos` → `CloseComm`
3. 回填表单字段；照片 Base64 上传 `SysFile`
4. 再调 `hrEmp/parseIdCard` 覆盖 `emp_province` / `emp_city`

## 客户机部署摘要

1. 拷贝厂商 `sdtapi.dll`（及依赖）到 Agent 目录或配置 `DllDirectory`
2. `dotnet run` 或发布 win-x86/x64 与 DLL 位数一致
3. 浏览器打开 EHR，放卡后点「读取身份证」

详见 Agent 目录 `README.md`。

## 配置

- **业务开关（唯一）：** 公司参数设置 → 参数明细 → **启用二代身份证**（`IdCardV2Enabled`）。
- **厂别解析：** 按**当前登录用户管辖部门**同属兜底（管辖均归属同一公司才取参）；**不**跟员工任职部门挂钩。管辖跨多公司或无法解析归属 → 不启用读卡并提示。
- 为「是」时显示「读取身份证」并可硬件读卡；为「否」时隐藏按钮。
- 本机 Agent 仅负责驱动读卡器（固定 `127.0.0.1:19196`）；DLL 路径等属客户机部署，见 Agent `README.md`，与公司参数无关。
