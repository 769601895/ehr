# 高级查询通用控件 — 实现计划

> **For agentic workers:** 按任务顺序落地；每任务可独立验收。

**Goal:** 通用高级查询控件（分组/方案/失效）+ 人员资料接入。

**Architecture:** 复用 `BaseFilter.Filter`；Application 层白名单 `HrAdvancedFilter`；方案表 + `HrAdvQuerySchemeService`；前端 `AdvQueryDrawer`。

**Tech Stack:** Vue3 + Element Plus、Admin.NET + SqlSugar、SQL Server。

**Spec:** `doc/分析文档/高级查询通用控件/01-设计方案.md`

## Global Constraints

- SQL 按日归档 `doc/sql/yyyy-MM-dd/`
- 列表排序仍走 `OrderBuilder`；高级条件不替代左树状态/部门
- 字段白名单必做，禁止任意属性进表达式
- UI 至少 zh-CN / en（推荐 th/vi/zh-TW）

## Review Focus

- 失效字段未改完仍能查 → 必须拦截
- 分享后无交集角色不应看见方案
- 未注册 fieldKey 不得进 SQL
- 自定义布局删列后打开旧方案应标红
- 左树 empState/ccCode 与高级树根逻辑并且
