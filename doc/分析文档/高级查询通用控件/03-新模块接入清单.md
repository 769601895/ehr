# 新模块接入高级查询清单

配套规则：`.cursor/rules/adv-query-required.mdc`  
参考页：`Web/src/views/hrms/emp/index.vue`  
控件入口：`Web/src/components/advQuery/index.ts`

## 前端

1. `import { AdvQueryDrawer, useAdvQuery } from '/@/components/advQuery'`
2. `const adv = useAdvQuery('你的moduleCode')`
3. 按列表可查字段填充 `adv.setFields([...])`（布局/字段池/静态列均可）
4. 工具栏按钮 `adv.open()`；抽屉 `@search` → `adv.applySearch` + 刷新列表
5. `pageXxx({ ..., filter: adv.filter.value })`；重置调用 `adv.reset()`

## 后端

1. Page 入参用 `BasePageInput`（自带 `Filter`）
2. 为本实体增加 FieldRegistry，在 `Page` 中 Apply（可仿 `HrAdvancedFilter.HrEmpRegistry` / `ApplyEmp`）
3. 代码类、名称存别处的字段登记跨表/码表处理器
4. 方案：现有 `hrAdvQueryScheme` + 权限按钮即可，勿新建方案表

## 不要做

- 页面内自绘另一套条件树 UI
- 前端直接拼 SQL / 未登记字段
- 每个模块复制方案存取 API
