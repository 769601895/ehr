# 04-工号规则可配置生成方案

日期：2026-10-31  
**上位通用方案：** [05-动态字段赋值规则引擎方案.md](./05-动态字段赋值规则引擎方案.md)（工号 = 算子 `compose` 的一种）。  
关联：公司参数 `EmpIdMode` / `EmpIdFixedPrefix` / `EmpIdLength`；专项原型 `原型-工号规则配置.html`；通用原型 `原型-动态字段赋值规则.html`。

---

## 1. 目标与原则

| 目标 | 说明 |
|------|------|
| 规则可见可配 | 人事在前端看到「工号怎么拼」，可改段顺序/类型，不必改后端 `switch` |
| 发号仍在后端 | 预览可前后端；正式发号必须服务端加锁/号段，防并发撞号 |
| 兼容现状 | 现有码表选项作为**预置模板**；自定义规则存 JSON/段表 |

**非目标（本期不做）：** 仅浏览器生成并落库；无限 DSL/脚本；跨系统分布式发号中心。

---

## 2. 现状

- 公司参数仅**保存**编码方式码值与固定号、长度。
- 下拉来自 `code_mstr`（`EmpIdMode`），文案可维护，**生成行为未引擎化**。
- 新增一种拼法（如固定号+年月+符号+流水）仍需认识新 `code_value` 或写死分支。

---

## 3. 方案概览

```text
┌─────────────────┐     保存规则      ┌──────────────────┐
│ 前端规则编排 UI  │ ───────────────► │ HrEmpIdRule      │
│ 模板 / 段列表   │                   │ (+ 段表或 JSON)  │
│ 样例预览        │ ◄── Preview API ──│                  │
└─────────────────┘                   └────────┬─────────┘
                                               │ 入职发号
                                               ▼
                                      ┌──────────────────┐
                                      │ EmpIdGenerator   │
                                      │ + HrEmpIdSeq     │
                                      └──────────────────┘
```

1. **段（Segment）模型**：工号 = 有序段拼接。  
2. **模板**：把现有 EmpIdMode 映射为内置段组合；用户可「基于模板自定义」。  
3. **解释器**：后端按段类型渲染；流水段走号段表。  
4. **前端**：拖拽/表格维护段；即时预览；高级用户改自定义，普通用户只选模板。

---

## 4. 段类型（封闭枚举）

| type | 含义 | 主要参数 | 示例 |
|------|------|----------|------|
| `fixed` | 固定号前缀 | 取自公司参数或段内常量 | `XM` |
| `literal` | 字面量 | `value`（白名单字符） | `-` |
| `date` | 日期部件 | `format`: `yy`/`yyyy`/`MM`/`dd` | `202603` |
| `seq` | 流水号 | `length`、`pad`、`scope` | `0007` |
| `manual` | 不生成 | 入职时手填 | — |

**流水 scope 建议：** `global` | `site` | `site+yyyy` | `site+yyyyMM`（与段中日期粒度对齐）。

**特殊符号：** 仅允许配置里的白名单（如 `-` `_`），避免门禁设备拒识。

---

## 5. 与现有 EmpIdMode 映射（预置模板）

| code | 名称 | 段组合（示意） |
|------|------|----------------|
| 0 | 自动流水号 | `seq(length=EmpIdLength, scope=site)` |
| 1 | 手工维护 | `manual` |
| 4 | 固定号+流水号 | `fixed` + `seq` |
| 5 | 4位年+月+流水号 | `date(yyyy)` + `date(MM)` + `seq(scope=site+yyyyMM)` |
| 8 | 固定号+年+月+符号+流水 | `fixed` + `date(yyyy)` + `date(MM)` + `literal` + `seq` |
| 9 | 固定号+年+月+流水 | `fixed` + `date(yyyy)` + `date(MM)` + `seq` |

切换模板时覆盖段列表；勾选「自定义」后改段不再回写码值语义，或另存 `ruleMode=custom`。

---

## 6. 数据模型（建议）

### 6.1 规则头（每厂别一条，可挂在公司参数旁）

`HrEmpIdRule`：`Id`, `SiteCode`, `TemplateCode`(可空), `IsCustom`, `EmpIdLength`, `LiteralAllow`, `Remark`, 审计字段。

或在 `HrCompanyParam` 增加 `EmpIdRuleJson`（NVARCHAR(MAX)）——**快速落地**；段多、要审计时再拆表。

### 6.2 段表（可选）

`HrEmpIdRuleSeg`：`RuleId`, `OrderNo`, `SegType`, `Format`, `LiteralValue`, `SeqLength`, `SeqScope`, `PadChar`。

### 6.3 号段表（必做，发号用）

`HrEmpIdSeq`：`SiteCode`, `ScopeKey`, `NextVal`, 行级锁/更新。  
`ScopeKey` 例：`*` / `2026` / `202603`。

---

## 7. API（合约草案）

| API | 说明 |
|-----|------|
| `GET/POST .../empIdRule/detail` | 按厂别取规则+段 |
| `POST .../empIdRule/save` | 保存（校验段、白名单、至少一段） |
| `POST .../empIdRule/preview` | 入参：规则快照 + 模拟日期/固定号 → 返回样例串（**不占号**） |
| `POST .../empIdRule/next`（内部） | 入职服务调用：占号并返回正式工号 |

校验：`seq` 必须存在且唯一一段；`literal`∈白名单；总预估长度 ≤ 约定上限。

---

## 8. 前端交互（与原型一致）

1. **选模板** → 载入预置段。  
2. **段列表** → 上移/下移/删除/新增；类型切换显示参数。  
3. **固定号 / 长度 / 符号** → 参与预览。  
4. **样例预览** → 前端本地拼装演示；正式环境可再调 Preview API。  
5. **保存** → 写入规则；公司参数页「工号编码方式」可改为「模板+是否自定义」双态。

入口建议：公司参数「参数明细」内嵌「工号规则」折叠区，或独立子页；人事代码表继续只维护模板显示名。

---

## 9. 分阶段落地

| 阶段 | 内容 | 价值 |
|------|------|------|
| P0 | 段 JSON 存公司参数 + Preview（可先前端预览）+ 文档/原型对齐 | 配置可见 |
| P1 | 后端 Generator + `HrEmpIdSeq`，入职调用 `next` | 真正发号 |
| P2 | 段表拆分、权限、规则变更审计、多语模板名 | 运维完备 |

---

## 10. 风险与约束

- 规则变更**不回溯**已发工号；只影响新入职。  
- 自定义规则错误会导致号段混乱 → 保存前强校验 + 预览强制看一眼。  
- 考勤/IC 若要求纯数字，UI 上禁止 `literal` 非数字或提供「仅数字模式」开关。
