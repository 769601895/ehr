# 公司参数设置 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付全新「公司参数设置」双页签模块（厂别列表 + 参数明细），宽表 `HrCompanyParam` + 译文 `HrCompanyParamLang`，下拉 `code_field` 等于列名，支持多语言。

**Architecture:** 后端 Admin.NET 动态 API（对齐 `HrPostService`）；主表一行一厂别、强类型列仅含截图字段；下拉走既有 `HrCodeMstrService.GetCodeList`；前端 Vue 双页签 + `useVxeTable` 远程排序。

**Tech Stack:** Admin.NET / SqlSugar / Furion；Vue3 + Element Plus + vxe-grid；`code_mstr` / `code_mstr_lang`；`HrUiCulture`。

**Spec:** `doc/分析文档/公司参数设置/01-详细开发解决方案.md`  
**码值来源:** `doc/分析文档/HR系统参数设置/01-参数明细设置表字段与下拉取值.md`（仅截图字段）

## Global Constraints

- 禁止使用表 `hr_sys_mstr` 及任何 `sys_*` 列名。
- 库表/列名 **PascalCase、无 `_`**；下拉 `code_field` **等于列名**（如 `EmpIdMode`）。
- 字段范围 **仅** SPEC §2.2 截图清单；截图没有的不建列、不做 UI。
- SQL 新稿一律写入 `doc/sql/2026-10-30/`（按日归档）。
- 列表必须远程排序：`field` / `order` / `descStr` + 后端 `OrderBuilder`。
- 文化：`zh-CN` / `zh-TW` / `en` / `th` / `vi`（`HrUiCulture`）。
- 参考实现：`HrPostService`、`Web/src/views/hrms/post/index.vue`、`Web/src/views/system/config/index.vue`（排序）。

## Review Focus

- 重复 `SiteCode` 新增 → `HR_CP_SITE_DUP`，不写脏数据。
- 非法下拉码提交 → `HR_CP_CODE_INVALID`。
- `EmpIdMode≠固定号+流水(4)` 时保存仍接受空 `EmpIdFixedPrefix`；为 4 时允许有值。
- 切换 `Accept-Language=en` 后 Page/GetCodeList 显示英文，存库码不变。
- 软删后同 `SiteCode` 可再新增（唯一约束须排除已删或应用层校验只查未删）。

### Task 4: DTO + HrCompanyParamService

**Files:**
- Create: `Admin.NET/Admin.NET.Application/Service/Hr/CompanyParam/Dto/HrCompanyParamDto.cs`
- Create: `Admin.NET/Admin.NET.Application/Service/Hr/CompanyParam/HrCompanyParamService.cs`

**Interfaces:**
- Consumes: `SqlSugarRepository<HrCompanyParam>`、`HrCompanyParamLang`；`HrCodeMstrService.GetCodeList`；`HrUiCulture`  
- Produces API（Name=`hrCompanyParam`）:

```csharp
Task<SqlSugarPagedList<HrCompanyParamOutput>> Page(HrCompanyParamPageInput input);
Task<HrCompanyParamOutput> Detail([FromQuery] long? id, [FromQuery] string siteCode);
Task<long> Add(HrCompanyParamAddInput input);          // SiteCode + SiteName → Defaults → Insert；返回 Id
Task Update(HrCompanyParamUpdateInput input);         // 全量明细字段 + Id
Task Delete(BaseIdInput input);                       // 软删主表 + 删 Lang
Task<List<HrCompanyParamLangOutput>> LangList([FromQuery] long id);
Task SaveLang(HrCompanyParamLangSaveInput input);     // 对齐 HrPost SaveLang
```

- `HrCompanyParamPageInput` : `BasePageInput` + 可选 `Keyword`  
- `Page`：`OrderBuilder(input, defaultSortField: nameof(HrCompanyParam.SiteCode), descSort: false)`；`SiteName` 按当前 culture 解析  
- Update 校验：`WorkCycleDay`/`AttCloseDay`∈[0,31]；`OtMinUnitHour>=0`；每个下拉字段值必须落在 `code_mstr`（`code_field=列名`）  
- 错误：`HR_CP_SITE_DUP` / `HR_CP_NOT_FOUND` / `HR_CP_CODE_INVALID` / `HR_CP_SITE_CODE_EMPTY`

- [ ] **Step 1: 实现 DTO + Service 上述签名**

  模式抄 `HrPostService`（Page/Get/Delete/LangList/SaveLang）；Add 用 Defaults。

- [ ] **Step 2: 手工 API 冒烟（或最小集成测）**

  - Add `SiteCode=T01` → Detail 有默认值  
  - 再 Add 同码 → `HR_CP_SITE_DUP`  
  - Update 非法 `EmpIdMode=99` → `HR_CP_CODE_INVALID`  
  - SaveLang en 名称 → Page 带 `Accept-Language: en` 见英文名  

- [ ] **Step 3: `dotnet build` 通过**
