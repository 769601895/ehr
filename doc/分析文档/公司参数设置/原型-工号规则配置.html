功能说明

  1. 1 基础参数

    厂别级固定号、流水位数。与公司参数中的固定号/工号长度对齐，参与段渲染。

  2. 2 预置模板

    映射现有 EmpIdMode（0/1/4/5/8/9）。选模板载入段；「自定义」后可改段而不改码表选项。

  3. 3 规则段编排

    生成过程在前端可见：fixed / date / literal / seq / manual。后端用同一段列表解释执行。

  4. 4 预览 ≠ 发号

    预览不递增号段；入职 API 走锁与 HrEmpIdSeq，保证并发唯一。
