# SPEC：公司参数设置模块（全新设计）

> 来源需求：`公司参数设置模块.docx`（桌面截图）  
> 下拉码值参考：`doc/分析文档/HR系统参数设置/01-参数明细设置表字段与下拉取值.md`（**仅用于截图已有字段的取值**；PBL）  
> 生成日期：2026-10-30  
> 约束：**禁止沿用**老表 `hr_sys_mstr` 及 `sys_*` 字段名；全新建表、新字段名；必须支持多语言  
> **字段范围：以 docx 截图可见字段为准；截图没有的一律不建列、不做 UI**  
> **命名：列名无下划线（PascalCase）；`code_field` 与对应列名相同**

---

## 1. 摘要

### 1.1 要做什么

在新 EHR（Admin.NET + Vue）中交付「公司参数设置」模块：按**公司/厂别**维护一套人事/考勤/薪资/保险业务参数。界面为**双页签**：

| 页签 | 能力 |
|------|------|
| 系统选项设置 | 厂别列表；增删改；双击进入明细 |
| 参数明细设置 | 分组表单编辑当前厂别参数并保存 |

工具栏需有「语种配置」，用于维护厂别名称等多语言。

### 1.2 明确不做（Non-Goals）

- 不读写、不继续使用 `hr_sys_mstr` / `sys_*`。
- **不做**截图未出现的参数列（即使旧表/提取文档有）。
- 本期不做「预警参数设置」页签。
- 不替代平台级 `SysConfig`。
- 不在本期做参数变更审计流水。

### 1.3 设计决策一览

| 决策 | 选择 | 理由 |
|------|------|------|
| 字段范围 | **仅 docx 截图可见项** | 用户明确要求 |
| 列命名 | **PascalCase、无 `_`** | 如 `EmpIdMode`；与 C# 属性同名 |
| code_field | **等于列名** | 如列 `EmpIdMode` → `code_field='EmpIdMode'`，前后端同一标识 |
| 表结构形态 | **宽表一行一厂别** | 与分组表单一一对应 |
| 下拉码表 | **`code_mstr` + `code_mstr_lang`** | 已有多语言链路 |
| 界面文案 | **vue-i18n** | 标签/分组/按钮 |
| 厂别名称多语言 | **`HrCompanyParamLang`** | 对齐 `HrPostLang` 模式 |
| 主键 | Snowflake `Id` + 唯一 `SiteCode` | 对齐 `EntityBase` |

## 6. 前端方案

### 6.1 路由与菜单

- `/hrms/companyParam`；权限 `hrCompanyParam:page|add|update|delete|lang`。

### 6.2 页结构

```text
index.vue
  tab-site   → siteList（siteCode / siteName 可排序）
  tab-detail → detailForm（四组，仅 §2.2）
  toolbar：语种配置 | 新增 | 删除 | 保存 | 刷新
```

交互：

1. 双击列表 → 明细。  
2. 新增：录入 `SiteCode` + `SiteName`，默认参数后进明细。  
3. `EmpIdMode` 为「固定号+流水」时启用 `EmpIdFixedPrefix`。  
4. 下拉：`codeList({ codeField: 'EmpIdMode' })`，与列名一致。  
5. 无部门 Org 选择。

### 6.3 列表排序

`useVxeTable`；默认 `siteCode` asc；请求 `field` 用实体 camelCase（`siteCode`）。

### 6.4 语种配置

五行维护各文化 `SiteName`。

## 7. API

`HrCompanyParamService` → `api/hrCompanyParam`

| Method | Path | 说明 |
|--------|------|------|
| POST | `/page` | 分页 |

## 13. 假设

1. 字段 = 截图清单；码值来自提取文档中的对应旧字段。  
2. 列名 / 表名 PascalCase、**不含 `_`**。  
3. **`code_field` ≡ 列名**（不再使用 `hr_cp_*` 前缀）。  
4. 2 页签；厂别由本模块维护 `SiteCode`/`SiteName`。  
5. JSON 序列化为 camelCase（`empIdMode`），与库列 `EmpIdMode` 由框架映射。
