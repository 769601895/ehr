# 人事月报

发薪前的人事关账模块：按厂别 + 薪酬月生成计薪名单与人事事实快照，冻结后供薪酬消费；保留考勤月界与考勤资格等输入供考勤月报计算，**不存工时结果**；人事属性跟 `hrEmp` 动态字段池（`monthSnap`）快照；月内异动轨迹跟 `hr_emp_chg_field` 自定义可改项走。

## 一句话

不是看板、不是保险月报、不是界面布局定义；是**薪酬输入契约**。

## 与现网关系

- 吃：人员主档、异动/离职/停职、公司参数月界、人事管辖  
- 暂不吃：考勤引擎（未建）、薪酬引擎（未建）  
- 不混用：`reportDef`、`InsMonthReportMode`
