# 人事月报 P0 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地人事月报 P0：按厂别+薪酬月开批、推导考勤月界、生成计薪名单与人事/异动快照、人工调整、校验、冻结/解冻、导出与薪酬只读消费 API。

**Architecture:** 新建 `hr_emp_month_batch` / `hr_emp_month_line` 与 `HrEmpMonthService`；月界由 `HrEmpMonthPeriodResolver` 纯函数从 `HrCompanyParam` 推导；名单按方案 D8 简化规则生成；人事属性经 `hrEmp` 场景 `monthSnap` 写入 `EmpFieldSnapshot`；月内异动轨迹按启用中的 `hr_emp_chg_field` 写入 `ChgFieldSnapshot`；前端批次列表 + 行明细（组织树面板 / 高级查询 / 动态列）。

**Tech Stack:** Admin.NET + SqlSugar（HR 库 `[Tenant(HrDb)]`）；Vue3 + Element Plus + vxe-grid + `useAdvQuery` + `OrgTree`；vue-i18n；既有 `HrCompanySiteResolveService` / `HrUserCcScopeService` / `HrUiModuleCatalog`。

**Spec:** [01-需求与详细设计方案.md](./01-需求与详细设计方案.md)（§2～§18；P0 范围见 §13）。

## Global Constraints

- 模块码 `hrEmpMonth`；表前缀 `hr_emp_month_*`；SQL 进 `doc/sql/{yyyy-MM-dd}/`。
- 业务键 `SiteCode + PayPeriod`（yyyyMM）唯一有效批次；跨公司不可混批。
- 读公司参数经批次已存 `SiteCode` 或 `HrCompanySiteResolveService`；缺参报错，不猜。
- **不存**应出勤/实出勤/请假/加班等工时列；保留 §7.5 考勤输入字段。
- 人事快照唯一来源 `hr_ui_field_def` + `monthSnap`；异动轨迹唯一来源启用中的 `hr_emp_chg_field`；禁止另建字段字典、禁止写死仅部门/岗位。
- 固有列与 JSON 去重（§9.5）：`empId/empName/empState/empSal/ccCode/postId/dutyId/empInDate/empLeaDate/empKqIndate/empKqLeaDate` 不进 `EmpFieldSnapshot`。
- 列表：`page-list-sorting`、`adv-query-required`（P0 仅固有列）、`list-org-tree-panel`、`i18n-multilang-required`、`emp-id-input-scope`、`company-param-resolve`。
- 高级查询 `moduleCode=hrEmpMonth`；权限查询/开批生成/调整/冻结/解冻/导出分按钮。

## Review Focus

1. 缺 `AttCloseDay` / `PayrollAttMonth`（或公司参数不存在）时开批失败，无静默默认月界。  
2. 同 `SiteCode+PayPeriod` 已有有效批时再开被拒。  
3. 管辖外人员不进生成名单；手工纳入仍过 `lookupByEmpId` / 保存侧管辖校验。  
4. 冻结后改主档部门，已冻行 `CcCode` / 快照不变；未冻结重生成才刷新。  
5. `Consumed` 状态解冻被拒；`MarkConsumed` 幂等；下月生效异动不进本月 `ChgFieldSnapshot`，期末主快照仍为异动前。

### Task 1: 考勤月界解析器（纯逻辑）

**Files:**
- Create: `Admin.NET/Admin.NET.Application/Service/Hr/EmpMonth/HrEmpMonthPeriodResolver.cs`
- Create: `Admin.NET/Admin.NET.Application.Tests/Service/Hr/EmpMonth/HrEmpMonthPeriodResolverTests.cs`（若无 Tests 项目则放同解决方案可跑测项目；无则用可执行的最小断言类并在 Task 末注明手工对照表）

**Interfaces:**
- Produces:
  - `record EmpMonthPeriodResult(string PayPeriod, string AttMonth, DateTime AttFrom, DateTime AttTo)`
  - `static EmpMonthPeriodResult Resolve(string payPeriod, int attCloseDay, int payrollAttMonth)`
- Consumes: 无 DB

算法（方案 §6.2）：
1. `payPeriod` 须为 6 位 yyyyMM，非法抛错。  
2. `PayrollAttMonth=0` → AttMonth=当月；`=1` → 上月；其它值抛错。  
3. `close`：`0` 或 `31` 且当月天数不足 → 当月月末；`>当月天数` → 月末；否则用 close 日。  
4. close 为月末 → AttFrom=月初、AttTo=月末；否则 AttTo=AttMonth 的 close 日，AttFrom=上月 close+1 日。

- [ ] **Step 1:** 写失败用例：`Resolve("202611", 25, 0)` → AttMonth=`202611`，AttFrom=`2026-10-26`，AttTo=`2026-11-25`。  
- [ ] **Step 2:** 写用例：`AttCloseDay=31` 且 11 月 → 自然月整月；`PayrollAttMonth=1` + `PayPeriod=202611` → AttMonth=`202610`。  
- [ ] **Step 3:** 写用例：非法 `payPeriod`、非法 `payrollAttMonth` 抛错。  
- [ ] **Step 4:** 实现 `Resolve` 使上述通过。  
- [ ] **Step 5:** Commit：`feat(hrEmpMonth): period resolver`

### Task 5: 名单生成 / 重生成

**Files:**
- Create: `Admin.NET/Admin.NET.Application/Service/Hr/EmpMonth/HrEmpMonthGenerateService.cs`

**Interfaces:**
- Produces:
  - `Task GenerateAsync(long batchId, bool fullReset, ...)`  
    - 状态须 `Draft|Generated|Reopened`  
    - `fullReset=false`：删非 `ManualLock` 行后重算；保留 `ManualLock` 行的 Include/Exclude/原因/备注，**仍重刷**两份 Snapshot（方案 §18.3）  
    - `fullReset=true`：清空全部行后全量重算  
  - 生成后批次 → `Generated`；写/更新 `ParamSnapshot`（若开批已写则保持或刷新策略：**生成时再读参覆盖 ParamSnapshot**，开批已有一份则生成覆盖为最新——计划定：**开批写一次，生成不改 ParamSnapshot，避免中途改参污染**；`FieldSchemaSnapshot` 每次生成更新）
- Consumes: Task1 Resolver（仅用于校验批头月界已存在）、Task4 SnapBuilder、`HrUserCcScopeService.ApplyEmpScopeAsync`、`HrEmpLeavePayCmd`、停职表（有则标 `IsSuspend`）

纳入规则（§7.1 + D8）：
- OR：窗内在职/停职粗判；`EmpInDate`∈窗；`EmpLeaDate`∈窗；存在 `pay_period=PayPeriod` 有效薪资指令  
- AND 排除：入职晚于 AttTo；`EmpKqIndate` 有值且晚于 AttTo；管辖外  
- 窗前已离职且无窗内在职天数且无本月指令 → 不进  
- 窗内有已生效异动/停职 → `HasChgInPeriod`/`IsSuspend` + Warn 人工核对（不阻断）  
- `NeedAttendance`：Include 且个人考勤资格与窗有交集（空则回退入离职日）

期末主快照（D11/P0）：直接读主档当前值。
