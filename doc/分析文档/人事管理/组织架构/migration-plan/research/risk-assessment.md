# Risk Assessment — HrOrg

| ID | 风险 | 等级 | 缓解 |
|----|------|------|------|
| R1 | 实体含库中不存在的列导致写失败 | 高 | DDL/实体严格对齐约定列 |
| R2 | 服务仍物理删除或仍碰 SysOrg | 高 | 软停用；评审禁止 SysOrg |
| R3 | 产品/代码残留迁移痕迹（Legacy、SyncFrom…） | 高 | `00-roadmap` 禁止清单；命名评审 |
| R4 | 误用框架机构权限过滤人事树 | 中 | 人事树无 SysOrg 数据权限 |
| R5 | 人员表未就绪无法校验占用 | 中 | 先落 `h_emp_mstr` 依赖列；可开关 |
| R6 | CodeFirst 误加列 | 高 | 生产以 DDL 为准 |
| R7 | 同级 `cc_level` >99 | 低 | 一期数字规则；溢出需产品决策 |

## 回滚

- DDL：先备份再 `DROP` 本模块新建表。  
- 应用：停用菜单 / Git 回退。  
- **不**回退到 SysOrg 双写或迁移型 API。
