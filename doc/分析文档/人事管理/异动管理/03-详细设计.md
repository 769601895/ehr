## 1. 设计摘要

| 项 | 定案 |
|----|------|
| 业务 | 员工组织属性异动（部门必改确认、岗位可选） |
| 必填 | 工号、异动日期、新部门 |
| 审核 | 模块内：草稿 → 审核中 → 通过/驳回；**无流程配置也能完整闭环** |
| 生效 | 通过后进入待生效；`异动日期 ≤ 今天` 才写 `h_emp_mstr` |
| 撤销 | 仅已生效；按异动前回滚实际写过的列 |
| 不做什么 | 不调用测试用 `hrEmh` 流程；不写 `hr_wf_effect_*` 路径 |

```text
┌────────────┐   提交    ┌────────────┐   通过    ┌────────────────┐
│ 草稿 Draft │ ───────► │ 审核中     │ ───────► │ 待生效 Approved │
└────────────┘          └────────────┘          └────────┬───────┘
                              │ 驳回                      │ 到日 Apply
                              ▼                           ▼
                        ┌──────────┐              ┌──────────────┐
                        │ 已驳回   │              │ 已生效       │──撤销──► 已作废
                        └──────────┘              └──────────────┘
                                                      │
                                                      ▼ 写主档 + h_emh_hist
```

## 3. 状态与权限

### 3.1 状态码（存库英文，界面中文）

| 存库值 | 界面 | 可操作 |
|--------|------|--------|
| Draft | 草稿 | 改、删、提交 |
| InReview | 审核中 | 通过、驳回 |
| Approved | 已通过待生效 | 仅系统写回 |
| Effective | 已生效 | 撤销 |
| Rejected | 已驳回 | 只读 |
| Voided | 已作废 | 只读 |

### 3.2 权限按钮（建议 Permission）

| 权限码 | 含义 |
|--------|------|
| `hrEmpChg/page` | 列表查询 |
| `hrEmpChg/add` | 新增草稿 |
| `hrEmpChg/update` | 改草稿 |
| `hrEmpChg/delete` | 删草稿 |
| `hrEmpChg/submit` | 提交 |
| `hrEmpChg/approve` | 通过 |
| `hrEmpChg/reject` | 驳回 |
| `hrEmpChg/void` | 撤销 |

一期允许自审（提交人可点通过）。数据范围：与人员资料相同的组织数据权限。

### 5.5 核心算法（伪代码，中文注释）

#### 5.5.1 发起拦截 `AssertCanOpen`

```csharp
/// <summary>
/// 校验该员工是否允许开单/改日期保存。
/// 拦截集合：Draft / InReview / Approved / Effective（不含本单）。
/// </summary>
async Task AssertCanOpen(string empId, DateTime chgDate, long? excludeId)
{
    var list = await 查询同人工号且状态∈BlockStatuses且未删除且Id≠excludeId;

    // R5：已有审核中 → 禁止
    if (list.Any(x => x.Status == InReview))
        throw Oops.Oh("该员工已有审核中的异动单，不能再发起");

    // R5：已有待生效 → 禁止再开（与审核中同等防双头）
    if (list.Any(x => x.Status == Approved))
        throw Oops.Oh("该员工已有待生效的异动单，不能再发起");

    // R6：存在更晚异动日 → 禁止开更早单
    if (list.Any(x => x.ChgDate.Date > chgDate.Date))
        throw Oops.Oh("已存在更晚日期的异动记录，不能插入更早的异动");

    // R7/R13：同日已有在途或已生效 → 禁止
    if (list.Any(x => x.ChgDate.Date == chgDate.Date))
        throw Oops.Oh("该员工同一异动日已有单据，请先处理或撤销后再开");

    // 拦截集合内最多一张草稿（不含本单）
    if (list.Count(x => x.Status == Draft) >= 1)
        throw Oops.Oh("该员工已有草稿异动单，请先处理后再开");
}
```

#### 5.5.2 提交 `Submit`

```csharp
/// <summary>草稿提交：校验必填 → 拦截 → 改状态为审核中</summary>
async Task Submit(long id)
{
    var bill = await 加载主表及明细(id);
    if (bill.Status != Draft) throw Oops.Oh("仅草稿可提交");

    // 必填：工号、异动日期、类别、新部门
    if (string.IsNullOrWhiteSpace(bill.EmpId)) throw ...;
    if (bill.ChgDate == default) throw ...;
    if (string.IsNullOrWhiteSpace(bill.ChgType)) throw ...;
    var deptAfter = bill.Lines.First(x => x.FieldKey == ccCode).ValueAfter;
    if (string.IsNullOrWhiteSpace(deptAfter)) throw Oops.Oh("新部门不能为空");

    await AssertCanOpen(bill.EmpId, bill.ChgDate, bill.Id);

    bill.Status = InReview;
    bill.SubmitTime = now;
    bill.SubmitUserId = 当前用户;
    await 保存();
}
```

#### 5.5.3 通过 `Approve` + 尝试生效

```csharp
/// <summary>审核通过 → 待生效；若异动日已到则立即写员工资料</summary>
async Task Approve(long id)
{
    var bill = await 加载并锁行(id);
    if (bill.Status != InReview) throw Oops.Oh("仅审核中可通过");

    bill.Status = Approved;
    bill.ApproveTime = now;
    bill.ApproveUserId = 当前用户;
    await 保存();

    // 异动日已到（含补录过去日期）：马上尝试写主档
    if (bill.ChgDate.Date <= DateTime.Today)
        await _apply.TryApplyAsync(bill.Id);
}
```

#### 5.5.4 写员工资料 `TryApply`（唯一入口）

```csharp
/// <summary>
/// 生效写回：把明细「异动后」写入 h_emp_mstr。
/// 注意：value_after 为空则跳过该列，绝不清空岗位。
/// </summary>
async Task TryApplyAsync(long chgId)
{
    // 事务 + 锁异动单
    var bill = await 锁单(chgId);
    if (bill.Status != Approved) return;                    // 幂等：非待生效直接返回
    if (bill.ChgDate.Date > DateTime.Today) return;         // 未到日

    var emp = await 按工号加载员工(bill.EmpId)
              ?? throw Oops.Oh("员工不存在，无法生效");

    var written = new List<string>(); // 实际写入的列

    foreach (var line in bill.Lines.OrderBy(x => x.SortNo))
    {
        if (string.IsNullOrWhiteSpace(line.ValueAfter))
            continue; // R11：未填异动后 → 不改该列

        // 白名单：一期仅允许 cc_code、post_id
        if (line.DbColumn == "cc_code")
        {
            emp.CcCode = line.ValueAfter.Trim();
            written.Add("cc_code");
        }
        else if (line.DbColumn == "post_id")
        {
            emp.PostId = line.ValueAfter.Trim();
            written.Add("post_id");
        }
        // 其它列一期忽略，防误写
    }

    if (!written.Contains("cc_code"))
        throw Oops.Oh("生效失败：新部门未写入");

    await 更新员工主档(emp);

    bill.Status = Effective;
    bill.EffectiveTime = now;
    bill.AppliedColumns = string.Join(",", written);
    await 保存异动单(bill);

    await 写入HEmhHist(bill); // 留痕，便于报表
}
```

#### 5.5.5 撤销 `Void`

```csharp
/// <summary>已生效撤销：按异动前回滚 AppliedColumns，单据作废</summary>
async Task Void(long id, string? reason)
{
    var bill = await 锁单(id);
    if (bill.Status != Effective) throw Oops.Oh("仅已生效可撤销");

    // R8：存在更晚且仍在拦截集合的单 → 拒绝
    var later = await 同人且ChgDate更大且Status∈BlockStatuses;
    if (later.Any()) throw Oops.Oh("存在更晚的异动记录，不能撤销本单");

    var emp = await 按工号加载员工(bill.EmpId);
    var cols = (bill.AppliedColumns ?? "")
        .Split(',', StringSplitOptions.RemoveEmptyEntries);

    foreach (var col in cols)
    {
        var line = bill.Lines.FirstOrDefault(x => x.DbColumn == col);
        if (line == null) continue;

        // 回滚到异动前（允许 before 为空，表示清空——仅当当初确实写过该列）
        if (col == "cc_code") emp.CcCode = line.ValueBefore;
        if (col == "post_id") emp.PostId = line.ValueBefore;
    }

    await 更新员工主档(emp);

    bill.Status = Voided;
    bill.VoidTime = now;
    bill.VoidUserId = 当前用户;
    bill.VoidReason = reason;
    await 保存();
}
```

### 6.1 列表页 `empChg/index.vue`

- 使用 `useVxeTable`，远程排序；`Local` 记忆 `defaultSort` / `pageSize`（key：`localPageParam:hrEmpChg`）。

```ts
// 列表查询：把分页与排序传给后端（与系统配置页同一套路）
const params = Object.assign(state.queryParams, {

  pageSize: page.pageSize,
  field: sort.field,
  order: sort.order,
  descStr: 'desc',
});
```

列建议：异动单号、工号、姓名、异动日期、类别、原部门、新部门、状态、维护信息、操作。
