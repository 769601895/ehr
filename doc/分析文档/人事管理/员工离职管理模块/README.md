## 约定

| 项 | 约定 |
|----|------|
| 菜单位置 | 人事管理 → 离职管理 |
| 设计立场 | **HR 专家方案**；不以旧系统为规格来源 |
| 一期形态 | 独立模块；模块内提交/通过/驳回；离职日**次日**生效；恢复日**当日**生效 |
| 子菜单 | 离职原因设置（码表）/ 员工离职处理 / 复职管理（同工号） |
| 码表 | `LeaveReason` / `LeaveType` / `LeaveSalarySettle` |
| 关联主档 | `h_emp_mstr`（`emp_state` / `emp_lea_date` 等） |
| 分析日期 | 2026-11-10（方案）；2026-10-13（旧字段提取存档） |
| 状态 | 一期已落地：表 + API + 页面 + Job；需重启后端并重新登录 |
