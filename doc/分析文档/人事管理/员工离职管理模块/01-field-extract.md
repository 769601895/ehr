# 员工离职管理 — 界面字段提取

> 来源：旧系统「离职输入」窗体截图  
> 分析日期：2026-10-13

窗体分区：**员工信息**、**异动信息**、**维护信息**；底部操作：**存增** / **保存** / **返回**。

---

## 1. 员工信息

| 字段名 | 建议英文名 | 控件类型 | 备注 |
|--------|------------|----------|------|
| 异动单号 | `chgNo` / `trnNo` | 文本框 | 系统自动生成（界面红字提示） |
| 工号 | `empId` / `empNo` | 文本框 + 选择按钮（…） | 弹窗选人；选后回填下方只读信息 |
| 姓名 | `empName` | 文本框 | 一般由工号带出 |
| 部门名称 | `deptName` / `ccName` | 文本框（跨两列） | 一般由工号带出 |
| 职务名称 | `jobName` | 文本框 | 一般由工号带出 |
| 岗位名称 | `postName` | 文本框 | 一般由工号带出 |
| 入职日 | `hireDate` | 日期框 | 一般由工号带出 |
| 转正日 | `regularDate` | 日期框 | 一般由工号带出 |
| 合同起始日 | `contractStart` | 日期框 | 一般由工号带出 |
| 合同终止日 | `contractEnd` | 日期框 | 一般由工号带出 |

---

## 2. 异动信息

| 字段名 | 建议英文名 | 控件类型 | 默认值/示例 | 备注 |
|--------|------------|----------|-------------|------|
| 离职日 | `leaveDate` | 日期框 | `0000-00-00` | 业务必填（待确认） |
| 异动类别 | `chgType` | 文本框 | `离职` | 本场景固定为离职 |
| 离职类型 | `leaveType` | 下拉框 | — | 字典/代码类 |
| 离职原因 | `leaveReason` | 下拉框 | — | 字典/代码类 |
| 薪资结算 | `salarySettle` | 下拉框 | `手续正常发薪` | 影响当月发薪，见下方提示 |
| 备注 | `remark` | 文本框（跨列） | — | |
| 生效 | `effective` | 文本框 | `否` | 可能只读/流程回写，待确认 |
| 是否黑名单 | `isBlacklist` | 单选框 | `否` / `是` | 默认「否」 |

### 界面业务提示

> 薪资结算如是「手续未办停薪」或「自动离职无薪」，在薪资中将会停发该员工的当月薪资。

已知/可见的薪资结算选项示例：

| 选项文案 | 说明 |
|----------|------|
| 手续正常发薪 | 默认；正常发当月薪 |
| 手续未办停薪 | 停发当月薪 |
| 自动离职无薪 | 停发当月薪 |

（完整选项清单需对照旧库字典或代码类表补充。）

## 3. 维护信息

| 字段名 | 建议英文名 | 控件类型 | 备注 |
|--------|------------|----------|------|
| 维护人 | `updateBy` / `maintainer` | 文本框 | 一般系统写入，只读 |
| 维护时间 | `updateTime` | 文本框 | 一般系统写入，只读 |

---

## 4. 操作按钮

| 按钮 | 建议行为 |
|------|----------|
| 存增 | 保存当前记录后清空表单，继续新增 |
| 保存 | 保存当前记录 |
| 返回 | 关闭窗体 / 返回列表 |

---

## 5. 字段总清单（落库/对接用）

```
异动单号, 工号, 姓名, 部门名称, 职务名称, 岗位名称,
入职日, 转正日, 合同起始日, 合同终止日,
离职日, 异动类别, 离职类型, 离职原因, 薪资结算, 备注, 生效, 是否黑名单,
维护人, 维护时间
```

### 录入侧 vs 带出侧（初判）

| 类型 | 字段 |
|------|------|
| 用户录入/选择 | 工号、离职日、离职类型、离职原因、薪资结算、备注、是否黑名单 |
| 系统生成/回写 | 异动单号、异动类别、生效、维护人、维护时间 |
| 由工号带出（只读） | 姓名、部门名称、职务名称、岗位名称、入职日、转正日、合同起始日、合同终止日 |
