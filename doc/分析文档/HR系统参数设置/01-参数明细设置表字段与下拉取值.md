> 来源：`yuenan/hrs.pbl`

> 页签：`tabpage_2`，标题「参数明细设置」

## 2. 下拉字段（DDListBox / values=）

格式：`码 = 显示`。取值直接来自 DW 列定义 `values="显示\t码/..."`。

### 2.1 人事相关

| 字段 | 界面含义（参考） | 下拉取值 |
|---|---|---|
| `sys_emp_id` | 工号编码方式 | `0`=自动流水号；`1`=手工维护；`2`=2位年+流水号；`3`=4位年+流水号；`4`=固定号+流水号；`5`=4位年+月+流水号；`6`=1开始流水号；`7`=2位年+月+流水号 |
| `sys_emp_long` | 工号长度 | `0`=不固定（兼作特殊选项；实际长度多为数值编辑） |
| `sys_emp_intryout` | 新进试用否 | `0`=不试用；`1`=试用 |
| `sys_emp_try_type` | 试用期关联对象 | `0`=固定值；`1`=与职务关联；`2`=与岗位关联；`3`=与人员类别关联 |
| `sys_train_type` | 培训必修课对象 | `0`=空；`1`=岗位必修；`2`=职务必修；`3`=人员类别 |
| `sys_dim_mode` | 离职与恢复 | `0`=允许同一人操作；`1`=不允许同一人操作 |
| `sys_change_mode` | 停职与复职 | `0`=允许同一人操作；`1`=不允许同一人操作 |
| `sys_try_type` | 试用期限单位 | `0`=月；`1`=天 |
| `sys_try_indate` | 试用期当天是否有效 | `1`=是；`0`=否 |
| `sys_emp_saltype` | 计薪方式维护 | `0`=人事维护；`1`=薪资维护；`2`=保密 |
| `sys_emp_type` | 薪酬类别维护 | `0`=人事维护；`1`=薪资维护 |
| `sys_emp_grade` | 职等维护 | `0`=人事维护；`1`=薪资维护；`2`=保密 |
| `sys_rs_pic_type` | 启用二代身份证 | `1`=是；`0`=否 |
| `sys_apply_mode` | 流程审核 | `0`=必须一级审核；`1`=根据流程审核；`2`=单级审核 |
| `sys_rs_dimaudit` | 离职审核 | `0`=否；`1`=是 |
| `sys_rs_changeaudit` | 异动审核 | `0`=否；`1`=是 |
| `sys_rs_zzaudit` | 转正审核 | `0`=否；`1`=是 |
| `sys_main_flg` | 用户权限分配方式 | `0`=用户权限；`1`=岗位权限 |
| `sys_emp_ccedit_mode` | 人员批量分配 | `0`=无控制；`1`=权限控制；`2`=初分配下放 |
| `sys_xz_mode` | 薪资流程 | `0`=自动提交；`1`=手工提交 |
| `sys_xz_cost` | 成本中心单位 | `0`=按员工；`1`=按部门 |
| `sys_kq_monthday_mode` | 出勤天计算 | `0`=`>=4小时计半天`；`1`=`>4小时计1天` |
| `sys_kq_ovstok` | （DW 绑定本字段） | `0`=当日计；`1`=次日计 |
| `sys_kq_ovoff1` | 休息无卡视连班否 / 加班刷卡前下班相关 | `0`=计算；`1`=不计算 |

> 说明：迁移版 WinForms 中 `sys_kq_ovstok` 文案为「计连班/不计」，与 PBL 本 DW 的 `当日计/次日计` **不一致**；以 PBL `d_rs_ddw_sysoptions` 为准。

### 2.2 考勤相关

| 字段 | 界面含义（参考） | 下拉取值 |
|---|---|---|
| `sys_emp_kquser` | 员工考勤设置 | `0`=在人员资料中；`1`=在考勤管理中 |
| `sys_emp_ovini` | 加班类型默认值 | `0`=正常计加班；`1`=不计加班；`2`=周节日计加班；`3`=节日计加班；空码=空值 |
| `sys_emp_freeini` | 考勤方式默认值 | `0`=正常考勤；`1`=手工考勤；`2`=免刷卡；空码=空值 |
| `sys_emp_ic` | IC卡取值方式 | `0`=与工号一致(完全)；`2`=与工号一致(截零)；`1`=手工维护 |
| `sys_kq_monday` | 应出勤天计算 | `0`=正常工作日；`1`=全月天数；`2`=正常工作日(含节日) |
| `sys_kq_indate` | 入职日考勤 | `0`=是；`1`=第1天免考勤；`2`=前两天免考勤 |
| `sys_emp_leakq` | 离职日考勤否 | `0`=无薪不考勤；`1`=有薪需刷卡；`2`=有薪不考勤 |
| `sys_kq_ovstand` | 加班计算标准 | `0`=以实际时数；`1`=以半小时取整；`2`=以加班刷卡时间取整 |
| `sys_kq_ovaudit` | 加班审核 | `0`=否(按时间申请)；`2`=否(按小时申请)；`1`=是(按时间申请)；`3`=是(按小时申请) |
| `sys_kq_late` | 迟到计异常否 | `0`=是；`1`=否 |
| `sys_kq_leaveaudit` | 请假审核 | `0`=否；`1`=是 |
| `sys_kq_leave_unit` | 日报请假显示 | `0`=小时；`1`=天 |
| `sys_kq_forget` | 漏刷卡处理 | `0`=计漏刷卡；`1`=计旷工 |
| `sys_kq_woca_type` | 排班日历调整 | `0`=开放；`1`=关闭 |
| `sys_kq_leave_shift` | （请假班次/关联，DW 列名；提取时可能截断为 `sys_kq_le`） | `0`=关联控制；`1`=否 |
| `sys_kq_tdaudit` | （调班/相关审核） | `0`=否；`1`=是 |

### 2.3 薪资 / 保险 / 其它

| 字段 | 界面含义（参考） | 下拉取值 |
|---|---|---|
| `sys_emp_prph` | 奖惩计算方式 | `0`=按日薪比例；`1`=奖惩对应金额 |
| `sys_account_mode` | 银行账号管理模式 | `1`=单一帐户；`2`=多帐户 |
| `sys_prph_edit_enable` | （奖惩编辑方式） | `0`=与奖惩类型关联；`1`=手工维护 |
| `sys_bx_parameter` | （DW 绑定本字段） | `0`=当月生成月报；`1`=次月生成月报 |
| `sys_bx_month_commit` | 保费提交薪资方式 | `1`=保费提交当月薪资；`2`=保费提交上月薪资 |
| `sys_bx_commit_mon` | （保险提交月份开关） | `0`=生成；`1`=不生成 |
| `sys_rs_changeday` | （异动日计算规则） | `0`=根据设置计算；`1`=`if(结束日<16,15,31)`；`2`=结束日月末；`3`=计算前推一天 |

> 说明：迁移版中 `sys_bx_parameter` 文案为「不根据合同生成人员 / 根据合同生成人员」，与 PBL 本 DW 的「当月/次月生成月报」**不一致**；以 PBL 为准。

## 4. 与迁移版差异（便于对照）

| 字段 | PBL `d_rs_ddw_sysoptions` | `NHR.Model/hr_sys_mstr` 字典 |
|---|---|---|
| `sys_emp_id` | 8 档（0–7，含年月流水等） | 仅 3 档：系统流水号/手工维护/集团工号 |
| `sys_kq_ovstok` | 当日计 / 次日计 | 计连班 / 不计 |
| `sys_bx_parameter` | 当月生成月报 / 次月生成月报 | 不根据合同生成人员 / 根据合同生成人员 |
| `sys_bx_month_commit` | 码值 **1 / 2** | 码值 **0 / 1**（文案相近） |
| `sys_emp_ic` | 截零=`2`，手工=`1` | 截零=`1`，手工=`2`（码与文案对调风险） |

做新 EHR 迁移时，**下拉码值请以本 PBL 提取结果为准**，并抽样核对现网 `hr_sys_mstr` 实际存值。

## 6. 库表结构核对（HR_2025，2026-10-30）

连通结果：`user-hr2025-sqlserver`（`10.0.11.111` / `HR_2025`）正常；`user-ehr-sqlserver`（`jack\sql2014`）仍超时；`user-tpkhr`（`localhost:1433`）仍失败。

`hr_sys_mstr` 共 72 列。与页签相关的类型摘要：

| 类型 | 字段 |
|---|---|
| 主键 `nvarchar(100)` | `sys_site`（默认 `((1))`） |
| `smallint` | `sys_emp_id`、`sys_emp_long`、`sys_emp_intryout`、`sys_emp_intrylong`、`sys_emp_movetrylong`、`sys_emp_prph` |
| `int`（多数下拉存码） | `sys_emp_*` / `sys_kq_*` / `sys_xz_*` / `sys_bx_*` / `sys_rs_*` / `sys_try_*` / `sys_account_mode` / `sys_main_flg` / `sys_apply_mode` 等 |
| `numeric/decimal` | `sys_kq_late`；`sys_kq_overmin(18,2)` |
| `nvarchar` 文本 | `sys_kq_absent`、`sys_kq_user`、`sys_rs_emp_pic`、`sys_web_address`、`sys_fileshare_path`、`sys_fix` 等 |

样例行（`sys_site=01`）：`sys_emp_id=1`，`sys_kq_ovstok=0`，`sys_bx_parameter=0`，`sys_bx_month_commit=1`，`sys_emp_ic=1`，`sys_account_mode=1`。
