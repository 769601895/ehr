# P0 定界与 hrEmpChg 字段初稿

日期：2026-11-11

## 定界

| 项 | 结论 |
|----|------|
| L1/L2 | 做：显隐、顺序、宽/占位、分组、必填/只读、控件、码表 |
| L3 | 不做进布局：审批按钮、流程开关 |
| P2 样板 | `hrEmpChg`（异动管理） |
| P2 范围 | **仅列表**接 Effective；表单为 P2.1 backlog |

## hrEmpChg 表单字段（配置中心 form 场景）

| FieldKey | 说明 | group | controlType | 备注 |
|----------|------|-------|-------------|------|
| chgNo / status / empId / empName / chgDate / chgType / chgReason / remark | 主表字段 | basic | text/select/date/… | 进 form |
| occText / opostText | 原部门 / 原岗位 | job | text（只读） | 进 form + list |
| nccText / npostText | 新部门 / 新岗位 | job | cascader / select | 进 form；运行时绑组织/岗位控件见 P2.1 |

最终 FieldKey 以实体/DTO camelCase 为准，种子时核对。
